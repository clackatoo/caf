CAF SI

The Standard Interface: how a chat with an agent should look and behave in any app built on CAF. Point an agent at it when integrating CAF, and it will build the expected thing, not something novel.

These pages are mock-ups: nothing on them is connected to CAF. They change over time. Every part is optional, and each says how firm it is.

The principle

CAF SI standardises a single chat: what CAF means. It deliberately says nothing about how an app arranges its chats. The test for any part: would a user moving between two CAF apps be confused or misled if it differed? If so, it's standard. Every app already has its own way of navigating its things (a sidebar, tabs, clackatoo's panes and workspaces). Guidance there would only push an app into growing a second one, which is the awkward integration CAF SI exists to prevent.

How firm each part is

Required

Everything inside a chat; how a chat is identified wherever it appears; the words and actions for what happens to a chat; colour roles. Copy these.

Suggested

Where there are a couple of good ways and the app should pick, such as how the usage page is laid out. Pick one; don't invent.

Up to the app

The app's own frame: where chats are listed, panes, windows, workspaces, projects (CAF's shelves), search, shortcuts, empty states. Use what the app already has.

Colour roles Required

The pages use clackatoo's colours as the default theme, in dark and light. An app may use its own palette, but keeps these roles.

Accent: act here. The lit Send button, the caret, primary buttons, what's chosen, something waiting on you. Kept to those, so it still means "here". Warning: it went wrong. Failed turns and steps, refusals, restores that can't happen. Caution: held or getting close. A setting change waiting for the turn to end, context or limits filling up, a session that was replaced. Link: something to follow, never to act on. CAF's voice: the CAF badge on what CAF itself says, so it never reads as the agent. Muted: everything that matters less: times, counts, the agent's thinking, steps once done.

Words

  • Users never see CAF's own words: shelf, loaded, put away, session, adapter. Use the app's words, or none.
  • CAF's close is shown as Archive. Closing a tab or a pane only puts a chat away.
  • CAF speaks in its own voice, marked as CAF, and the agent's words are quoted as the agent's. Neither is presented as the other.
