How it works

  • The banner is about the agent, not the chat: every chat with Claude shows the same one, and it changes in all of them at once.
  • It attaches to the composer, as questions do, so whatever needs the user is in one place.
  • It follows the agent's status, in every chat with it but an archived one: while it isn't installed, while a sign-in is under way, and while it's signed out. Once all's well it says so for a moment, and goes.
  • A question waiting on the user attaches first; the banner comes back once it's answered.
  • A message sent while the chat waits waits on the composer's tray. Not now, only while the chat waits, drops this chat's messages; Stop stops the install or sign-in for every chat.
  • Signing out, and every agent at once, are in the agents panel.

What CAF decides

  • Install: Unknown, Missing{size}, Installing{done, size}, Installed{version}, Cannot(Node | Npm | Platform | NoRecipe | Failed(Offline | Corrupt | NoSpace | Stopped | Patch | Other)), or Host (the app starts it, so there's no Install).
  • Sign-in: Unknown, SignedOut, SigningIn{url?, code?, paste}, or SignedIn(Account | ApiKey | Gateway | Unknown). Offer Sign in only while can_sign_in is true.
  • A chat waits (WaitingForAgent) for an agent CAF installs until it's installed, and while a sign-in started when it was signed out is under way. Not for an agent that's merely signed out.
  • A viewer without the agents right gets no link or code from CAF, so it can only say what's happening.
